# 🧮 BMI Calculator App

Modern BMI Calculator built using Flutter & Dart with clean UI and responsive design.

---

## ✨ Features

- Calculate BMI instantly
- Responsive UI
- Height Slider
- Weight & Age Controls
- Dark Modern Design
- Smooth Navigation

## 🚀 Getting Started

### Clone Repository

```bash

```

### Install Dependencies

```bash
flutter pub get
```

### Run Application

```bash
flutter run
```
