# 🧮 BMI Calculator App

Modern BMI Calculator built using Flutter & Dart with clean UI and responsive design.

---

## ✨ Features

- Calculate BMI instantly
- Responsive UI
- Height Slider
- Weight & Age Controls
- Dark Modern Design
- Smooth Navigation

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/George838-arch/flutter-bmi-calculator.git
```

### Install Dependencies

```bash
flutter pub get
```

### Run Application

```bash
flutter run
```
