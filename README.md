# 🚀 Getting Started

## 1️⃣ Clone Repository

```bash
git clone https://github.com/George838-arch/flutter-bmi-calculator.git
```

---

## 2️⃣ Navigate to Project

```bash
cd flutter-bmi-calculator
```

---

## 3️⃣ Install Dependencies

```bash
flutter pub get
```

---

## 4️⃣ Run Application

```bash
flutter run
```

---

# 🧠 BMI Formula

```math
BMI = \frac{Weight\ (kg)}{Height^2\ (m)}
```
